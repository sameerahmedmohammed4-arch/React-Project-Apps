# React Counter App

A simple Counter application built using React and Vite. This project is designed as a beginner-friendly React application to understand the basics of state management and event handling.

## 📌 Project Description

The React Counter App allows users to increase or decrease a number using two buttons.

- Clicking the **+ button** increases the counter by 1.
- Clicking the **- button** decreases the counter by 1.
- The counter starts at **0**.
- The updated value is displayed immediately on the screen.

This project demonstrates how React manages changing data using the `useState` Hook.

## 🚀 Features

- Simple and clean counter interface
- Increment counter by 1
- Decrement counter by 1
- Displays the current counter value
- Uses React state management
- Beginner-friendly project structure

## 🛠️ Technologies Used

- **React** – JavaScript library for building the user interface
- **Vite** – Development and build tool
- **JavaScript (JSX)** – Used to create React components
- **HTML** – Structure of the application
- **CSS** – Optional styling
